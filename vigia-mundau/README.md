# Vigia Mundaú (Next.js + Tailwind + Framer Motion)

## Rodar localmente
```bash
npm install
npm run dev
```
Abra http://localhost:3000

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: Add New > Project > importe o repositório (o Next.js é detectado sozinho).
3. Opcional: defina `NEXT_PUBLIC_SITE_URL` com o endereço final do site (usado na pré-visualização de links).

## Arquivos de mídia (pasta public)
- `video.mp4`: vídeo do topo.  `poster.jpg`: quadro mostrado antes do vídeo carregar.
- `og.jpg`: imagem de pré-visualização para WhatsApp e redes sociais.
